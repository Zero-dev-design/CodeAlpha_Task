TASK 1 — AI LANGUAGE TRANSLATOR
-------------------------------

Description:
------------
A web-based multilingual language translation application developed using Python Flask.

Features:
---------
- Translate text between multiple languages
- Text-to-Speech support
- Pause/Continue/Restart speech playback
- Copy translated text
- Modern responsive user interface
- Language swap feature
- Support for multiple Indian and international languages

Technologies Used:
------------------
- Python
- Flask
- HTML
- CSS
- JavaScript
- deep-translator
- gTTS

Purpose:
--------
The project demonstrates:
- API integration
- Frontend and backend connectivity
- Speech synthesis
- UI/UX implementation
- Real-time translation functionality
